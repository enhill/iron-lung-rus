# Проверка перевода в игре

`Harness.cs` — тестовый плагин-«автопилот». После запуска игры он сам:

- открывает настройки, переключает инверсию и проверяет, что `settings.ini` не портится;
- показывает вступление, брифинг, карту, записку и финальные экраны;
- открывает все статьи терминала по очереди, затем цепочку запросов с читами и русскими запросами;
- записывает отрисованный текст всех надписей в `harness_out/log.txt` и делает скриншоты в `harness_out/`;
- закрывает игру.

`typer.ps1` печатает текст в окно игры через системный ввод, чтобы проверить настоящий набор с клавиатуры. Запуск с `IL_TYPE_TEST=1`.

## Только на копии игры

Игра открывает достижения Steam при чтении терминала и записки. Автопилот блокирует их, но всё равно:

1. Скопируйте папку игры, например в `C:\tmp\IronLungTest`, и поставьте туда русификатор.
2. В `settings.ini` копии поставьте `fullscreen=0`. `steam_appid.txt` не трогайте: если подставить туда `480`, в вашем профиле Steam последней игрой будет значиться «Spacewar».
3. Соберите плагин тем же способом, что и `plugin/build.ps1` (дополнительно нужны ссылки на `UnityEngine.ScreenCaptureModule.dll`), и положите `ILHarness.dll` в `BepInEx\plugins` копии.
4. Запустите `Iron Lung.exe` из копии и дождитесь, пока игра закроется сама.

Не кладите `ILHarness.dll` в настоящую установку игры и не включайте его в релиз.
