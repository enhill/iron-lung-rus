# Как помочь с переводом

Спасибо, что хотите сделать перевод лучше. Есть два пути.

## 1. Сообщить о проблеме

[Создайте обращение](https://github.com/enhill/iron-lung-rus/issues/new/choose) и выберите шаблон:

- **Исправление перевода** — опечатка, неточность, неудачная фраза. Укажите, где в игре это видно, как сейчас и как лучше. Скриншот очень помогает.
- **Русификатор не работает** — игра осталась на английском, квадратики вместо букв, вылеты. Приложите файл `BepInEx\LogOutput.log` из папки игры.

## 2. Исправить самому

Откройте нужный файл на GitHub, нажмите карандаш ✏️, внесите правку и нажмите **Propose changes**. GitHub сам создаст копию репозитория и pull request. Через пару минут автопроверка покажет, всё ли в порядке, а на странице проверки появится готовый архив **IronLung_RUS** — его можно скачать и попробовать в игре.

### Где какой текст

| Что в игре | Файл |
|---|---|
| Главное меню, настройки, подсказки, карта, выход из игры | `package/BepInEx/Translation/ru/Text/RuHUD.txt` |
| Вступление, брифинг, финал | `package/BepInEx/Translation/ru/Text/RuText.txt` |
| Статьи терминала и русские запросы к ним | `src/terminal/01_…txt` … `15_…txt` |
| Заголовок терминала | `src/terminal/00_header.txt` |
| «Неизвестный запрос» и ответы на чит-коды | `src/terminal/responses.txt` |
| Субтитры к голосу по радио (начало игры) | `package/BepInEx/plugins/IronLungRu/subtitles.txt` |
| Размер шрифта отдельных надписей | `package/BepInEx/Translation/ru/Text/resizer.txt` |
| Записка (картинка) | `package/BepInEx/Translation/ru/Texture/notebookpaperbg […].png`, текст для справки — `imgText.txt` |

### Файлы RuHUD.txt и RuText.txt

Каждая строка — `оригинал=перевод`. Это формат XUnity.AutoTranslator, у него есть строгие правила:

- **Меняйте только то, что справа от первого `=`.** Левая часть должна побуквенно совпадать с текстом игры, иначе перевод не подхватится.
- **Знак `=` внутри перевода пишите как `\=`** (например, `<color\=red>`). Строку с лишним `=` XUnity молча выбросит. Автопроверка это ловит.
- `\n` — перенос строки, `\r` оставляйте как в оригинале.
- `{{A}}`, `{{B}}` — места, куда игра подставляет числа. Не удаляйте их из перевода.
- Не пишите `//` внутри перевода — с него начинается комментарий.
- Строки, начинающиеся с `//`, — комментарии.

### Файлы терминала (src/terminal)

У каждой статьи свой файл с разделами:

```
=== ОРИГИНАЛ (не редактировать, только для справки) ===
английский текст

=== ЗАПРОСЫ ===
русские варианты запроса, по одному в строке

=== ТЕКСТ ===
перевод статьи
```

- Пишите текст как обычно, с настоящими переносами строк. Экранировать ничего не нужно, `tools/build.py` сделает это сам.
- Раздел **ОРИГИНАЛ** — только для сравнения, при сборке он не используется.
- Красным `<color=red>…</color>` выделяются темы, по которым есть своя статья. Каждую такую ссылку игрок должен суметь ввести, поэтому её текст (без кавычек и дефисов, в нижнем регистре) должен быть в разделе **ЗАПРОСЫ** какой-нибудь статьи. Если нет — автопроверка подскажет, что добавить.
- В **ЗАПРОСЫ** пишите только строчные буквы, цифры и одиночные пробелы: игра не даёт набрать дефис, точку или кавычки. Вариант с «е» вместо «ё» добавляется автоматически.
- Терминал выводит всё строчными буквами, но в исходнике пишите с заглавными, как в обычном тексте.

## Глоссарий и стиль

| Оригинал | Перевод | Запрос |
|---|---|---|
| The Quiet Rapture | Тихое Вознесение | тихое вознесение |
| Blood Ocean(s) | Кровавый океан, кровавые океаны | кровавые океаны |
| The Consolidation of Iron, c.o.i | Железный Союз | железный союз |
| conviction realization | реализация приговора | реализация приговора |
| The Iron Lung | «Железное лёгкое» | железное легкое |
| SM-13, SM-8 | SM-13, SM-8 (латиницей, как на корпусе подлодки) | см13, sm13 |
| Moon AT-5, Moon Z-8 | луна AT-5, луна Z-8 | ат5, луна з8 |
| EIC (Epoch of Interplanetary Colonization) | ЭМК, Эпоха межпланетной колонизации (ж. р.: «принятая ЭМК») | эмк |
| IMC (Interstellar Martian Calendar) | ММК, Межзвёздный марсианский календарь | ммк |
| Eden | Эдем | эдем |
| Filament Station | станция «Филамент» | филамент |
| `<redacted>` | `<засекречено>` | — |
| `[entry]` / `[body]` | `[запись]` / `[содержание]` | — |
| trench | впадина | — |
| point(s) of interest | точки интереса | — |
| burner sub | одноразовая лодка, расходник | — |

- **Обращение.** Официальные тексты (вступление, брифинг, база данных) обращаются к игроку на «вы». Записка на стене и тайное сообщение в статье SM-8 — на «ты»: их пишут такие же заключённые.
- **Типографика.** Кавычки «ёлочки», тире «—», букву «ё» пишем.
- **Числа.** Чтобы не возиться со склонением после подставляемых чисел, используем сокращения: «{{C}} ед.», «{{D}}°».
- **Мат.** В статье SM-8 он есть в оригинале — переводим так же грубо.
- **Длина.** Кнопки меню и подписи настроек узкие: проверяйте, что текст помещается (см. скриншоты в `docs`).

## Для мейнтейнеров

### Сборка локально

```
python tools/build.py          # только проверка и сборка файлов перевода в build/stage
python tools/build.py --zip    # плюс готовый архив dist/IronLung_RUS.zip
```

Нужен только Python 3.8+. При `--zip` скрипт скачивает официальные релизы BepInEx 5.4.23.2 и XUnity.AutoTranslator 5.4.0 и проверяет их SHA-256.

### Плагин IronLungRu

Исходник — `plugin/IronLungRu.cs`, собранная DLL лежит в `package/BepInEx/plugins/IronLungRu/`. Для сборки нужны библиотеки самой игры, поэтому на GitHub она не собирается. После правки исходника соберите DLL локально и закоммитьте её:

```
powershell -ExecutionPolicy Bypass -File plugin/build.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Iron Lung"
```

### Проверка в игре

В `tools/test` лежит тестовый «автопилот» — плагин, который проходит все экраны, открывает все статьи терминала и делает скриншоты. Запускайте его **только на копии игры**: см. `tools/test/README.md`.

### Выпуск новой версии

1. Обновите `VERSION` и добавьте раздел в `CHANGELOG.md`.
2. Создайте тег `vX.Y.Z` (например, через Releases → Draft a new release → Choose a tag) и отправьте его.
3. GitHub Actions соберёт архив и опубликует релиз с описанием из `CHANGELOG.md`. Ссылка «последняя версия» в README и руководстве Steam обновится сама.
